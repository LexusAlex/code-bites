# Удалить последний коммит вместе со всеми его изменениями

Полное удаление последнего коммита и его изменений из истории ветки.

```bash
# удалить последний коммит вместе со всеми его изменениями
# осторожно: изменения коммита будут потеряны безвозвратно
git reset --hard HEAD~1
```

::: tip Когда это нужно
- Случайная утечка секретов (паролей, ключей API)
- Полностью неверный подход
- Очистка «мусорных» коммитов
:::

::: danger Чего нужно бояться
- **Потеря несохранённых изменений:** если в папке были изменённые файлы, которые вы ещё не закоммитили, флаг `--hard` удалит их безвозвратно.
- **Проблемы с общим репозиторием:** если вы уже сделали `git push`, а затем локально выполнили `git reset --hard HEAD~1`, локальная ветка разойдётся с удалённой. Чтобы затереть историю на сервере, придётся использовать опасную команду `git push --force` — делать это в общих (командных) ветках категорически не рекомендуется, так как это сломает Git у ваших коллег.
:::
