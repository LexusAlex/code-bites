# Создать SSH-ключ Ed25519 в Linux

Создаёт пару SSH-ключей современного типа Ed25519:

```bash
ssh-keygen -t ed25519
```

Нажмите `Enter`, чтобы сохранить ключи по стандартным путям:

- приватный ключ — `~/.ssh/id_ed25519`;
- публичный ключ — `~/.ssh/id_ed25519.pub`.

Затем задайте парольную фразу для защиты приватного ключа. Пустую парольную фразу лучше использовать только в автоматизированной среде с подходящими мерами безопасности.

Публичный ключ можно вывести командой:

```bash
cat ~/.ssh/id_ed25519.pub
```

Публичный ключ разрешено передавать удалённому сервису или серверу. Файл `~/.ssh/id_ed25519` является приватным: не публикуйте и не передавайте его.
