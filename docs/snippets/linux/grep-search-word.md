# Поиск слова внутри файлов в linux

Рекурсивно ищет слово во всех текстовых файлах, начиная с текущего каталога `.`. Замените `.` на `/`, чтобы искать по всей корневой файловой системы — вариант с `find` при этом не зайдёт в смонтированные каталоги, `/proc`, `/sys` и т.д.

```bash
# найти слово "слово" от текущего каталога, не выходя за пределы файловой системы;
# 2>/dev/null прячет шум от "Permission denied" (или запустите под sudo)
find . -xdev -type f -exec grep -nwi -I -e "слово" {} + 2>/dev/null

# вариант с одним grep: короче, но зайдёт в смонтированные каталоги
grep -rnwi -I -e "слово" . 2>/dev/null
```

Пример вывода — `путь:номер строки:найденная строка`:

```text
./src/app.py:42: слово найдено в этом файле
```

::: tip Пояснение ключей find
- `-xdev` — не выходить за пределы одной файловой системы (аналог `-mount`; в grep такого ключа нет)
- `-type f` — искать только обычные файлы
- `-exec ... {} +` — передавать найденные файлы grep пачками
:::

::: info Пояснение ключей grep
- `-r` — рекурсивный обход каталогов (нужен только для варианта без find)
- `-n` — показывать номера строк
- `-w` — искать только целое слово
- `-i` — игнорировать регистр
- `-I` — пропускать бинарные файлы
- `-e` — защищает шаблон, начинающийся с дефиса; для обычного слова можно опустить
:::
