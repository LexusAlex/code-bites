# Поиск слова внутри файлов

Рекурсивно ищет слово во всех текстовых файлах, начиная с корня `/`, не переходя на другие файловые системы (смонтированные каталоги, /proc, /sys и т.д.).

```bash
# найти слово "слово" во всех файлах корневой файловой системы
find . -xdev -type f -exec grep -nwi -I -e "слово" {} +
# вариант с grep
grep -rnwi -I . -e "слово"
```

`find / -xdev -type f` — рекурсивно находит обычные файлы от корня, не выходя за пределы одной файловой системы (аналог `-mount`; в grep такого ключа нет), `-exec ... {} +` — передаёт файлы grep пачками. У grep: `-n` — показывать номера строк, `-w` — искать только целое слово, `-i` — игнорировать регистр, `-I` — пропускать бинарные файлы, `-e` — задаёт шаблон поиска.
