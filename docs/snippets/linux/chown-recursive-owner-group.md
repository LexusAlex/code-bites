# Рекурсивно сменить владельца и группу каталога

Назначает пользователя `test` владельцем каталога `site.test`, а группу `test` — его группой. Ключ `-R` применяет изменение также ко всем вложенным файлам и каталогам.

```bash
chown -R test:test site.test
```

Команда меняет владельца и группу, но не права чтения, записи и выполнения. Для её запуска обычно требуются права `root`; при необходимости добавьте `sudo`.

::: warning Осторожно
Перед выполнением проверьте путь к каталогу: из-за ключа `-R` ошибочно указанный путь изменит владельца и группу всего вложенного содержимого.
:::
