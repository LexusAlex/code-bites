# Поиск текста в Vim

Введите команду в обычном режиме и нажмите `Enter`:

```vim
/текст
```

Ищет `текст` вперёд от текущего положения курсора.

```vim
?текст
```

Ищет `текст` назад от текущего положения курсора.

После первого найденного совпадения используйте:

- `n` — перейти к следующему совпадению в направлении первоначального поиска;
- `N` — перейти к совпадению в обратном направлении.

Например, после поиска через `/` клавиша `n` перемещает вперёд, а `N` — назад. После поиска через `?` направления меняются местами.
