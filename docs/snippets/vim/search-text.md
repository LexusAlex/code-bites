# Поиск текста в Vim

Выполняйте команды в обычном режиме Vim:

```vim
" Поиск вперёд: введите /текст и нажмите Enter
/текст

" Поиск назад: введите ?текст и нажмите Enter
?текст

" Повторить поиск в том же направлении
n

" Повторить поиск в обратном направлении
N
```
